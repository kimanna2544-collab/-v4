# TOEIC MASTER — 최종판

토익 Part 5 유형별 속성암기 PWA. 자체 제작 연습문제 300개가 포함되어 있습니다. 실제 TOEIC 기출문제는 아닙니다.

## 주요 기능
- 6개 대분류 유형별 학습, 검색, 진도, 북마크, 오답 복습
- 속성암기(정답 즉시 표시) / 직접 풀기 모드
- 핵심 해설 접기·펼치기 및 A~D 선택지별 설명 펼치기
- 문제 문장 터치 시 정답을 빈칸에 넣어 미국 영어 TTS로 읽기
- 터치 스와이프, 이전/다음, 로컬 학습 기록 저장, 오프라인 캐시

## GitHub Pages 배포 (기존 저장소 업데이트)
1. ZIP을 풀고 **폴더 내부 파일**을 GitHub 저장소 최상위에 업로드합니다.
2. 기존 파일(index.html, app.js, style.css, questions.json, sw.js 등)을 같은 이름으로 교체합니다.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. 배포가 완료되면 Chrome에서 사이트를 열어 새로고침합니다. 설치된 앱이 구버전을 표시하면 앱을 완전히 종료한 뒤 다시 열어주세요.
5. Chrome ⋮ → 앱 설치 또는 홈 화면에 추가.

## 참고
- 300문제는 자체 제작 문제로, 일부는 동일한 문법 패턴을 다른 업무 상황에 적용하여 반복 학습하도록 구성했습니다.
- 문제은행의 새로운 270문제에는 선택지별 짧은 해설이 포함되어 있습니다. 기존 30문제의 선택지별 해설은 간단한 문법 근거를 바탕으로 제공됩니다.
- 음성은 스마트폰 브라우저의 Web Speech API에 의존하며 기기별 지원·음색이 다를 수 있습니다.
- 학습 기록은 기기의 localStorage에 저장되며 브라우저 데이터를 삭제하면 초기화될 수 있습니다.
